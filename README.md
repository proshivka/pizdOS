## ⚡ О проекте

**pizdOS** — это бескомпромиссная операционная система, созданная для тех, кому осточертели неповоротливые гиганты вроде Windows и раздутые дистрибутивы Linux. 

Никаких тяжелых фреймворков, никакого лишнего дерьма: чистый ассемблер x86, прямое общение с BIOS и железом, запуск с загрузочного сектора за 0.0001 секунды.

---

## 🔥 Фичи версии 1.0.0 (Bratukha Edition)

- **Настоящий MBR Bootloader (512 байт):** Читает ядро напрямую с секторов диска через `int 13h`.
- **Интерактивный командный шелл (`pizdOS>`):**
  - Полная поддержка ввода с клавиатуры через BIOS прерывания (`int 16h`).
  - Обработка Backspace, переполнение буфера, эхо-вывод.
- **Поддержка мастей (16 цветов VGA):** меняй цвет текста под настроение командой `color` / `mast`.
- **Матрица нахуй (`matrix` / `matrica`):** рандомизированный дождь из символов на портах таймера 8254 PIT.
- **Экран критического пиздеца (`panic` / `pizdec`):** собственный аналог BSOD.
- **Прямой опрос CMOS RTC (`time` / `vremya`):** реальное аппаратное время из чипа материнки.
- **PC Speaker Synth (`beep` / `pikni`):** генерация звука через порт `0x61`.
- **Жесткий аппаратный ребут (`reboot` / `vpizdu`):** сброс через контроллер клавиатуры 8042.

## 🛠️ Список встроенных команд

| Команда (Eng) | По-пацански | Описание |
| :--- | :--- | :--- |
| `help` | `huelp` | Вывести список всех доступных команд |
| `clear` | `nahuy` | Нахуй очистить весь экран |
| `echo <текст>` | `pizdi <текст>` | Вывести введенный базар в консоль |
| `info` | `poyasni` | Пояснить за систему и проверить размер RAM |
| `time` | `vremya` | Показать точное аппаратное время из CMOS |
| `beep` | `pikni` | Издать громкий писк через спикер |
| `color <0-F>` | `mast <0-F>` | Сменить цвет шрифта (`1`=Синий, `2`=Зеленый, `4`=Красный, `E`=Желтый) |
| `matrix` | `matrica` | Запустить бесконечную матрицу (выход — любая клавиша) |
| `panic` | `pizdec` | Вызвать Kernel Panic / экран критического пиздеца |
| `reboot` | `vpizdu` | Перезагрузить ПК через контроллер 8042 |

## 🚀 Запуск и сборка

### Требования
- `nasm`
- `qemu-system-x86_64` (с `qemu-system-gui`)
- `make`

### 1. Быстрый запуск на Windows
Просто запусти батник:
```cmd
run.bat
```

### 2. Сборка и запуск через терминал / WSL:
```bash
# Собрать образ pizdos.img
make all

# Запустить в QEMU
make run

# Запустить прямо в терминале (curses)
make run-curses
```
